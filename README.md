# 4VGymConBBDD

Repositorio para el Proyecto 4VGymEF
Módulo Acceso a Datos

---

## 🔹 Proyecto 4VGymEF:
- **Descripción:** Proyecto para incluir una base de datos en una API
- **Conceptos clave:** APIREST, LinQ, Modelos, Controladores, Repositorio arquitectura, css, Entity Framework, SQL Server


## 🚀 Cómo ejecutar los proyectos
1. Clona este repositorio:
   ```bash
   git clone https://github.com/adrianmivovan7-beep/4VGymConBBDD.git
   ```
2. En SQL Server donde tengas la base de datos ejecuta el archivo que pone los datos
3. Carga el SLN del proyecto en Visual Studio
4. Ejecuta la solución, siguiendo las intrucciones específicas por proyecto
